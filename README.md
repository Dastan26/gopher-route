# Гофер-маршрут

Квиз по бэкенду на Go для фронтендера: 10 станций от основ языка до
продакшена в Kubernetes. На каждой станции короткая теория, 8 вопросов
и практическое задание.

Это разминка. Основная практика — в
[gopher-incidents](https://github.com/Dastan26/gopher-incidents): там ты чинишь настоящий
сломанный сервис.

## Как открыть

Один файл без сборки и зависимостей:

```bash
open index.html
```

Или онлайн: https://dastan26.github.io/gopher-route/

Прогресс сохраняется в `localStorage` браузера.

## Что внутри

| Станция | Темы |
|---|---|
| 1 | Типы, структуры, слайсы, map, ошибки |
| 2 | Модули, go test, табличные тесты |
| 3 | net/http, роутинг, middleware, graceful shutdown |
| 4 | JSON, теги структур, JSON:API |
| 5 | Postgres, pgx, sqlc, транзакции, индексы |
| 6 | Слои, интерфейсы, цепочки ошибок |
| 7 | JWT, OIDC, Keycloak, 401 и 403 |
| 8 | Горутины, каналы, errgroup, гонки |
| 9 | Kafka, идемпотентность, outbox, Redis |
| 10 | Docker, пробы Kubernetes, метрики, pprof |
| Финал | 12 случайных вопросов со всего маршрута |

Чтобы пройти станцию, нужно ответить хотя бы на 6 вопросов из 8.
Типы вопросов: выбор ответа, «что выведет код», сборка кода из строк
и ввод команды.
